# Aurix_Launch

Aurix_Launch is a static landing page for **Aurix**, a music player. It introduces the app and links to downloads and its source. The page describes features including music search, a personal library, lyrics, and offline listening; it is not the Android player itself.

## Preview locally

Open `index.html` in a modern browser, or serve the repository over HTTP:

    python -m http.server 8000

Visit http://localhost:8000.

## Project files

The main page is `index.html`, with supporting visual assets under `src/`. Keep asset paths and download or source links up to date when editing the page.
