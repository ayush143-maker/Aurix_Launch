Install on Android

Aurix comes as an APK, so Android and Chrome will ask you to confirm a few things. That's normal. Here's what you'll see.

  1. DownloadTap Download APK. Chrome may say the file could harm your device. It says this for every APK, so tap Download anyway.
  2. Open the fileWhen it finishes, tap Open. You can also find AurixV7.apk in your Downloads.
  3. Let Chrome install itAndroid asks for this once. Tap Settings, switch on Allow from this source, then come back and tap Install.
  4. Play Protect pop-upYou may see a notice because Aurix isn't on the Play Store. Tap More details, then Install anyway. The code is public on GitHub if you want to look.
  5. Press playOpen Aurix, search a song, and you're done.
